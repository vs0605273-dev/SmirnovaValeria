# SmirnovaValeria
Приложение для генерации случайных паролей с графическим интерфейсом. Позволяет настраивать длину пароля и типы используемых символов, сохраняет историю сгенерированных паролей в JSON файл.

## Описание
Приложение для генерации случайных паролей с графическим интерфейсом на Python (Tkinter). Позволяет настраивать длину пароля (4-128 символов) и типы используемых символов (строчные/заглавные буквы, цифры, спецсимволы). Автоматически сохраняет историю последних 100 сгенерированных паролей в JSON-файл.

## Требования
- Python 3.6 или выше
- Tkinter (входит в стандартную библиотеку Python, дополнительная установка не требуется)

## Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/vs0605273-dev/SmirnovaValeria.git
cd SmirnovaValeria
```

1. Запустите приложение:

```bash
python итоговоетестирование.py
```

или

```bash
python3 итоговоетестирование.py
```

Возможности

· Настройка длины пароля: от 4 до 128 символов
· Выбор символов:
  · Строчные буквы (a-z)
  · Заглавные буквы (A-Z)
  · Цифры (0-9)
  · Специальные символы (!@#$%^&*)
· Генерация пароля с заданными параметрами
· Копирование пароля в буфер обмена
· Сохранение истории паролей в JSON файл (последние 100 записей)
· Просмотр истории в таблице
· Очистка истории

Примеры использования

Пример 1: Простой пароль

1. Установите длину: 8 символов
2. Выберите: строчные буквы + цифры
3. Нажмите "Сгенерировать пароль!"
4. Результат: "k4m7p9n2"

Пример 2: Сложный пароль

1. Установите длину: 16 символов
2. Выберите все типы символов
3. Нажмите "Сгенерировать пароль!"
4. Результат: "K#7mP@9nQ$2vL%8w"

Пример 3: Только цифры

1. Установите длину: 6 символов
2. Выберите только "Цифры"
3. Нажмите "Сгенерировать пароль!"
4. Результат: "394728"

Тестирование

Позитивные тесты

· Генерация пароля минимальной длины (4 символа)
· Генерация пароля максимальной длины (128 символов)
· Использование всех доступных символов

Негативные тесты

· Попытка генерации без выбора символов (ошибка)
· Попытка генерации с длиной менее 4 (ошибка)
· Попытка генерации с длиной более 128 (ошибка)

Граничные случаи

· Генерация пароля только из одного типа символов
· Генерация при выборе двух типов символов
